# Secret Cipher

A simple Python command-line application that encrypts and decrypts messages using a shift-based cipher.

## Features
- Encrypt messages using a numeric key
- Decrypt messages using the same key
- Handles invalid input safely (menu + key validation)
- Clean interactive command-line interface
- Modular design (separates logic and interface)

## How it works
The program shifts characters in a custom character set using a user-provided key.

## How to run

```bash
python main.py


## Example

Input:
Message: Hello
Key: 5
